# 🧠 2の補数マスター (2's Complement Master - 4-Bit Edition)

2の補数の概念を「仕組みの理解」と「反復練習」の両面から短時間でマスターできるWeb学習アプリです。  
画面が左右に分割されており、左側で補数の理論や変換手順を確認しながら、右側でランダム生成される4ビット問題に挑戦できます。

---

## 🌟 特徴

- **左右2分割の学習スタイル**
  - **左画面（解説エリア）:** 2の補数の概念、変換の2ステップ（反転＋1）、4ビット（-8〜+7）の対応表を常時表示。
  - **右画面（練習エリア）:** ランダムに出題される練習問題でインタラクティブにテスト。
- **2パターンの出題形式**
  - 10進数 ➔ 4ビット2の補数（2進数）への変換
  - 4ビット2の補数（2進数） ➔ 10進数への変換
- **レスポンシブ＆モダンデザイン**
  - ダークモード基調で見やすく、PC・タブレット・スマートフォンのいずれでも快適に操作可能。
- **インストール不要**
  - 単一のHTMLファイル（HTML/CSS/JS一体型）で動作するため、ブラウザで開くだけですぐに使えます。

---

## 📁 使い方

1. 本リポジトリの `index.html`（または作成したHTMLファイル）をダウンロードします。
2. ファイルをダブルクリックして、お使いのWebブラウザ（Google Chrome, Safari, Edge, Firefox等）で開きます。
3. **左画面**の解説を参考にしながら、**右画面**の解答欄に答えを入力して「解答する」ボタン（またはEnterキー）を押します。

## 📖 2の補数の基本ルール（4ビット）

### 2の補数の作り方（2ステップ）
1. **反転:** 対象の正の数（2進数）の全ビット（0と1）を反転させる（1の補数）
2. **+1:** 反転した結果に `1` を加算する

### 4ビットでの表現範囲
- 表現可能範囲: **-8 〜 +7**
- 最上位ビット（左端）: **0なら正/ゼロ、1なら負**

| 10進数 | 2進数（2の補数） | 備考 |
|:---:|:---:|:---|
| **+7** | `0111` | 最大値 |
| **+1** | `0001` | |
| **0** | `0000` | |
| **-1** | `1111` | 0001を反転(1110) + 1 |
| **-3** | `1101` | 0011を反転(1100) + 1 |
| **-8** | `1000` | 最小値 |
